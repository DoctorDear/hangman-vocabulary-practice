# Hangman ฝึกคำศัพท์

เกมทายคำภาษาอังกฤษใน Terminal พร้อมคลังคำศัพท์ที่ผู้ใช้เพิ่ม ค้นหา และลบได้ เหมาะสำหรับฝึกจำคำจากคำใบ้ และฝึกอ่านโปรแกรม Python พื้นฐานร่วมกันสองคน

## วิธีรัน

เปิด Terminal ในโฟลเดอร์ `rush` แล้วรัน:

```sh
python main.py
```

ถ้าเครื่องใช้คำสั่ง `python3` ให้ใช้ `python3 main.py` ใช้ Python 3 และตรวจสอบเวอร์ชันที่ผู้สอนกำหนดอีกครั้ง โปรแกรมไม่ต้องติดตั้งแพ็กเกจเพิ่ม ใช้ `json`, `random`, `os` และ `sys` จาก standard library

ให้รันใน Terminal จริง เช่น Windows Terminal หรือ Terminal ใน VS Code เพื่อให้ล้างหน้าจอได้ ระหว่างเกมจะล้างและวาดใหม่ที่ด้านบน รูปจึงอยู่ตำแหน่งเดิม ถ้าส่งผลลัพธ์เข้าไฟล์หรือรันในช่อง Output ที่ไม่ใช่ Terminal โปรแกรมจะพิมพ์ต่อกันโดยไม่สั่งล้างหน้าจอ

## เมนู

| ตัวเลือก | การทำงาน |
| --- | --- |
| 1. Play Hangman | สุ่มคำจากคลังแล้วเริ่มเกม |
| 2. Add word | เพิ่มคำภาษาอังกฤษหนึ่งคำพร้อมคำใบ้ |
| 3. View / search words | ค้นหาจากคำหรือคำใบ้ กด Enter เพื่อดูทั้งหมด ผลลัพธ์เรียงตามความยาวคำจากสั้นไปยาว |
| 4. Delete word | พิมพ์คำที่ต้องการลบออกจากคลัง |
| 5. Exit | ออกจากโปรแกรม |

โปรแกรมโหลดคลังจาก words.json ข้าง main.py อัตโนมัติตอนเปิด ไฟล์ที่แจกมีคำตัวอย่าง 5 คำ คำที่เพิ่มและลบอยู่ใน RAM จนเลือกเมนู 6 เพื่อ Save; เมนู 7 ใช้อ่านไฟล์ซ้ำระหว่างใช้งาน หากไฟล์หายหรือเสียจะเริ่มด้วยคลังว่างพร้อมข้อความแจ้ง และยังเพิ่มคำแล้ว Save ได้

## กติกาและการตรวจข้อมูล

- คำศัพท์ใช้ตัวอักษรอังกฤษ `a-z` เท่านั้น ไม่มีเว้นวรรค ตัวเลข หรือเครื่องหมาย โปรแกรมตัดช่องว่างหัวท้ายและแปลงเป็นตัวพิมพ์เล็ก
- เพิ่มคำซ้ำไม่ได้ และคำใบ้ต้องไม่ว่าง คำใบ้สามารถใช้ภาษาไทยได้ถ้า Terminal รองรับ
- เริ่มเกมได้เมื่อคลังมีอย่างน้อยหนึ่งคำ
- เกมแสดงคำใบ้ ช่อง `_` ตัวอักษรที่ทายแล้ว จำนวนครั้งที่ผิด และรูป Hangman แบบ ASCII
- รูปเริ่มจากแท่นว่าง แล้วเพิ่มหัว → ลำตัว → แขนซ้าย → แขนขวา → ขาซ้าย → ขาขวา เมื่อทายผิดแต่ละครั้ง
- ทุกตาที่ทายจะวาดหน้าจอใหม่ พร้อมคำใบ้และข้อความผลของการทายครั้งก่อน เมื่อตัดสินแพ้หรือชนะแล้วจะรอให้กด Enter ก่อนกลับเมนู
- ทายครั้งละหนึ่งตัวอักษร ถ้าถูกจะเปิดทุกตำแหน่งของตัวอักษรนั้น
- ทายผิดครบ **6 ตัวอักษรที่ไม่ซ้ำกัน** จะแพ้และเฉลยคำ ถ้าเปิดครบก่อนจะแสดงว่าชนะ
- ตัวอักษรที่ทายซ้ำหรือข้อมูลที่ไม่ใช่ตัวอักษรอังกฤษหนึ่งตัวไม่ทำให้เสียโอกาส
- เมนูผิด ค้นหาไม่พบ และลบคำที่ไม่มีอยู่จะแสดงข้อความแล้วให้ใช้งานต่อ
- กด `Ctrl+C` หรือเมื่อไม่มีข้อมูลเข้าต่อไปแล้ว โปรแกรมจะออกพร้อมข้อความ Goodbye

## โครงสร้างข้อมูล

คลังคำศัพท์เป็น `list` ชื่อ `words` และแต่ละรายการเป็น `dictionary`:

```python
words = [
    {"word": "cat", "hint": "A small pet that says meow"},
    {"word": "apple", "hint": "A red or green fruit"},
]
```

- `words` เก็บได้หลายรายการ จึงเพิ่มด้วย `append()` และลบด้วย `remove()` ได้
- `item["word"]` อ่านคำศัพท์ ส่วน `item["hint"]` อ่านคำใบ้ของรายการนั้น
- ระหว่างเล่นมี `guesses` เป็น list เก็บตัวอักษรที่ทายแล้ว และ `mistakes` นับเฉพาะการทายผิด
- คลังคำเริ่มเป็น `[]` ใน `main()` แล้วโหลดจาก JSON ก่อนเข้าเมนู แล้วส่ง list เดิมให้ฟังก์ชันต่าง ๆ การเพิ่มและลบจึงอยู่ต่อเมื่อกลับเมนู

## ควรอ่านโค้ดตามลำดับไหน

1. เริ่มที่ `main()` ดูการโหลด JSON ตอนเริ่ม เมนู และการใช้ `while True` วนจนเลือกออก
2. อ่าน `add_word(words)` และ `delete_word(words)` เพื่อดูว่าการรับข้อมูลเปลี่ยน list อย่างไร
3. อ่าน `word_length(item)` และ `show_words(words)` เพื่อดูการประมวลผลข้อมูล
4. อ่าน `clear_screen()` และ `draw_hangman(mistakes)` แล้วอ่าน `play_game(words)` ตามลำดับ: เลือกคำ → เตรียมตัวแปร → ล้างหน้าจอและวาดสถานะปัจจุบัน → ตรวจแพ้ชนะ → รับตัวอักษร → อัปเดตเกมและข้อความผล
5. อ่านส่วน `if __name__ == "__main__":` ซึ่งเริ่มโปรแกรมเฉพาะเมื่อสั่งรันไฟล์นี้โดยตรง และจัดการการหยุดจากผู้ใช้

### แต่ละฟังก์ชันทำอะไร

| ฟังก์ชัน | รับอะไร | ทำอะไร / ส่งอะไรกลับ |
| --- | --- | --- |
| `word_length(item)` | dictionary หนึ่งคำ | `return` จำนวนตัวอักษร ใช้กำหนดลำดับคำ |
| `add_word(words)` | คลังคำ | ตรวจคำและคำใบ้ แล้วเพิ่มรายการ |
| `show_words(words)` | คลังคำ | ค้นหาและแสดงคำเรียงตามความยาว |
| `delete_word(words)` | คลังคำ | ค้นหาคำที่ระบุแล้วลบ หรือแจ้งว่าไม่พบ |
| `clear_screen()` | ไม่มี | ถ้ากำลังแสดงผลใน Terminal ให้สั่ง `cls` บน Windows หรือ `clear` บนระบบอื่น |
| `draw_hangman(mistakes)` | จำนวนครั้งที่ทายผิด | พิมพ์รูป Hangman ตามจำนวนครั้งที่ผิด ตั้งแต่ 0 ถึง 6 |
| `play_game(words)` | คลังคำ | เล่นหนึ่งรอบจนชนะหรือแพ้ |
| `main()` | ไม่มี | สร้างคลังคำและควบคุมเมนู |

ใน `sorted(words, key=word_length)` เราส่งชื่อฟังก์ชันให้ Python เรียกกับแต่ละรายการ ความยาวที่ฟังก์ชันคืนมาจะใช้จัดลำดับ โดย `sorted()` ไม่แก้ลำดับของ list ต้นฉบับ

`display` สร้างจากตัวอักษรที่เปิดแล้วกับ `_` เมื่อไม่มี `_` เหลือจึงถือว่าชนะ วิธีนี้ใช้ได้เพราะตอนเพิ่มคำเราห้ามเครื่องหมาย `_` อยู่แล้ว

ใน `draw_hangman()` เช่น `head = "O" if mistakes >= 1 else " "` หมายถึง ถ้าทายผิดตั้งแต่หนึ่งครั้งให้หัวเป็น `O` ถ้ายังไม่ผิดให้เป็นช่องว่าง ส่วนอื่นทำแบบเดียวกันตามลำดับ และเรียกวาดครั้งสุดท้ายเมื่อผิดครบ 6 ครั้งด้วย

`clear_screen()` ใช้ `sys.stdout.isatty()` ตรวจว่าแสดงผลใน Terminal และ `os.name` เลือกคำสั่งของระบบ ส่วน `message` ในเกมเก็บผลการทายไว้พิมพ์หลังล้างหน้าจอ จึงยังอ่านได้ในตาถัดไป การเช็กแพ้ชนะอยู่หลังวาดสถานะล่าสุด ทำให้เห็นรูปครบเมื่อแพ้และคำที่เปิดครบเมื่อชนะ

## เชื่อมกับเกณฑ์งาน 8 ข้อ

| เกณฑ์ | อยู่ตรงไหน |
| --- | --- |
| 1. เมนูและ input | เมนูทำงาน 4 ตัวเลือกไม่นับ Exit, ใช้ `input()` และ `print()` และกลับเมนูหลังจบงาน |
| 2. โครงสร้างและจัดการข้อมูล | คลังคำเป็น list ของ dictionary หลายรายการ เพิ่ม ดู และลบได้ในรอบการเปิดโปรแกรม |
| 3. เงื่อนไขอย่างน้อย 3 กฎ | ห้ามคำซ้ำ, ห้ามคลังว่างเริ่มเกม, ทายซ้ำไม่เสียโอกาส, ผิดครบ 6 ครั้งแพ้ และเปิดครบชนะ |
| 4. for และ while | `for` ตรวจคลังคำและเปิดตัวอักษร, `while` วนเมนูและเกม |
| 5. ฟังก์ชัน | มี 10 ฟังก์ชัน, 8 ฟังก์ชันรับพารามิเตอร์ และ `word_length()` คืนค่าความยาวที่นำไปใช้งานจริง |
| 6. ประมวลผลข้อมูล 2 อย่าง | ค้นหาแบบมีเงื่อนไขจากคำ/คำใบ้ และเรียงคำตามความยาว |
| 7. รับมือข้อมูลผิด | ตรวจเมนู คำศัพท์ คำใบ้ ตัวอักษรซ้ำ คลังว่าง และคำที่ไม่พบ |
| 8. ขั้นตอนใช้งานครบ | เพิ่มคำ → ค้นหาและดูคำ → เล่น → ลบ → ตรวจว่าคำนั้นหายไป |

ตารางนี้อธิบายการออกแบบตามเอกสารงาน ไม่ได้รับรองผลการประเมิน ทั้งสองคนต้องลองใช้งานและอธิบายโค้ดด้วยตนเอง

10. ลบทุกคำแล้วเลือกเล่น ต้องแจ้งว่าคลังว่าง และยังเพิ่มคำเพื่อเล่นต่อได้
11. รันใน Terminal และลองทายหลายครั้ง รูปต้องอยู่ด้านบนที่เดิม คำใบ้ต้องยังอยู่ ข้อความทายซ้ำหรือผิดต้องอ่านได้ และเมื่อจบเกมต้องเห็นผลค้างไว้จนกด Enter

## การรองรับ Terminal

บน macOS/Linux ฟังก์ชัน `clear_screen()` จะข้ามคำสั่ง `clear` เมื่อไม่มีค่า `TERM`, เป็นค่าว่าง หรือเป็น `dumb` เพื่อหลีกเลี่ยงข้อความเตือนจาก Terminal ส่วน Windows ใช้ `cls` ตามเดิม

## โบนัส: Save / Load JSON

ตามโจทย์ สามารถเลือกทำโบนัสอย่างน้อยหนึ่งอย่างหลังส่วนบังคับทำงานครบ เวอร์ชันนี้เลือกบันทึกและโหลดไฟล์ JSON เพื่อเก็บคลังคำที่ทีมเตรียมไว้ข้ามการเปิดโปรแกรม

- ตอนเปิดโปรแกรม เรียก `load_words(words, path)` อัตโนมัติจากคลังว่าง ถ้าอ่านไม่ได้จะไม่เขียนทับไฟล์จนกว่าจะสั่ง Save เอง
- เมนู **6. Save vocabulary** บันทึกคลังปัจจุบันไปที่ `words.json` ข้าง `main.py` การเซฟครั้งใหม่แทนที่ไฟล์เดิม
- เมนู **7. Load vocabulary** โหลดไฟล์นั้นและแทนที่คลังคำปัจจุบัน ถ้ามีคำที่ยังไม่ได้เซฟ ให้เลือก Save ก่อน Load
- โปรแกรมไม่เซฟอัตโนมัติ ก่อนออกต้องเลือก 6 หากต้องการเก็บการเพิ่มหรือลบคำ
- `save_words(words, path)` เขียนลงไฟล์ชั่วคราว `.tmp` ก่อน แล้วใช้ `os.replace()` แทนที่ไฟล์จริงเมื่อเขียนสำเร็จ ถ้าเซฟล้มเหลว ไฟล์เก่ายังอยู่
- `load_words(words, path)` ใช้ `json.load()` อ่าน ตรวจว่าเป็น list ของ dictionary ที่มีคำภาษาอังกฤษและคำใบ้ ตรวจคำซ้ำและข้อมูลผิดให้ครบก่อนใช้ `words[:] = loaded` เปลี่ยนคลังเดิม
- ถ้าไฟล์หาย เสีย รูปแบบผิด หรืออ่านไม่ได้ จะแจ้งข้อความและเก็บคลังคำในหน่วยความจำไว้ตามเดิม คลังว่าง `[]` ถือว่าถูกต้อง
- ใช้ standard library เท่านั้น ไม่มี dependency เพิ่ม

ลองสาธิต: เพิ่ม kiwi → เลือก 6 → ออก → เปิดใหม่ (โหลดอัตโนมัติ) → ค้นหา kiwi → ลบ kiwi → เลือก 6 → เปิดใหม่ คำที่ลบต้องไม่กลับมา

ทดสอบทั้งส่วนบังคับและโบนัสด้วย `python -m unittest discover -p "test_*.py"` จากโฟลเดอร์โปรเจกต์ ทั้งสองคนควรอธิบายความต่างระหว่างข้อมูลใน RAM กับ JSON, เหตุผลที่ตรวจไฟล์ก่อนเปลี่ยนคลัง และการใช้ไฟล์ชั่วคราวเพื่อป้องกันข้อมูลหายได้

ยังไม่ได้เพิ่ม login, รายงานสถิติ หรือ advanced algorithm เพราะไม่จำเป็นต่อโบนัส Save/Load นี้ การให้คะแนนโบนัสขึ้นกับการประเมินของผู้สอน
