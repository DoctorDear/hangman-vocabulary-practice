# Hangman Vocabulary Practice

A beginner Python terminal game with an editable vocabulary bank and progressive ASCII Hangman.

Run: `python rush/main.py`

Tests: `python -m unittest discover -p "test_*.py"`

See [the Thai guide](rush/README.md) for code explanations and team practice. Use menu 6 to save vocabulary to JSON and menu 7 to load it after restarting. Replace the placeholders in `rush/auteur` with real Intra logins before submission.
