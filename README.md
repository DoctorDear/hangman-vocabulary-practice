# Hangman Vocabulary Practice

A beginner Python terminal game with an editable vocabulary bank and progressive ASCII Hangman.

Run: `python rush/main.py`

Tests: `python -m unittest discover -p "test_*.py"`

See [the Thai guide](rush/README.md) for code explanations and team practice. Keep rush/words.json beside main.py. It loads automatically at startup. Use menu 6 to save edits and menu 7 to reload during a session. Missing or invalid files start an empty bank without overwriting the file. Replace the placeholders in `rush/auteur` with real Intra logins before submission.
