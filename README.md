# Hangman Vocabulary Practice

A beginner Python terminal game with an editable vocabulary bank and progressive ASCII Hangman.

Run: `python rush/main.py`

Tests: `python test_hangman.py`

See [the Thai guide](rush/README.md) for code explanations and team practice. Vocabulary changes last one session. Replace the placeholders in `rush/auteur` with real Intra logins before submission.
