เราเพิ่มอะไร เพราะอะไร
  1. 01
    เลือกเกมที่ทั้งทีมตามทัน
    เลือก Hangman และคลังคำศัพท์ ให้การจัดการข้อมูลเชื่อมกับการฝึกศัพท์อย่างชัดเจน
  2. 02
    ทำส่วนบังคับให้ครบก่อน
    เมนู 4 งานหลัก: เล่น เพิ่ม ดู/ค้นหา และลบ ใช้ทั้ง for, while, เงื่อนไข และฟังก์ชัน
  3. 03
    เพิ่มรูปคนแขวนและหน้าจอที่อยู่กับที่
    draw_hangman() วาดตาม mistakes ส่วน clear_screen() ล้างก่อนวาดใหม่ โดยเก็บข้อความตอบกลับไว้ใน message
  4. 04
    รับข้อเสนอแนะแล้วตรวจจริง
    แก้การเรียก clear เมื่อ TERM ไม่พร้อมบน macOS/Linux และตรวจ ZIP โดยไม่ลบไฟล์ตามรีวิวแบบไม่ตรวจสอบ
  5. 05
    เพิ่มโบนัส Save / Load JSON
    เซฟผ่านไฟล์ชั่วคราวก่อนแทนที่ไฟล์จริง โหลดแล้วตรวจข้อมูลครบก่อนเปลี่ยนคลังคำใน RAM
  6. 06
    ออกจากรอบได้ระหว่างเล่น
    พิมพ์ 0 กลับเมนูทันที ฟังก์ชันคืน "quit" ให้ main() ข้ามการรอกด Enter อีกครั้ง
